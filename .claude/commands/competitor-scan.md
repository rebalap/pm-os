# /competitor-scan

Activate when: running competitive intelligence on autism therapy software.
Can be triggered manually OR set as a weekly Claude Code Routine.

---

## What This Does

Scans the latest product updates from ATP's primary competitors, checks for India market signals, and produces a structured digest saved to the research folder. Run time: ~5–10 minutes.

---

## Process

**Step 1 — Run parallel Tavily searches** (run these simultaneously):

```bash
# Competitor product updates (last 30 days)
python3 tools/tavily-search.py "CentralReach new features product update 2026" --depth advanced --max-results 6 --topic news
python3 tools/tavily-search.py "Motivity ABA software update release 2026" --depth advanced --max-results 6 --topic news
python3 tools/tavily-search.py "Catalyst ABA app new features 2026" --depth advanced --max-results 5 --topic news
python3 tools/tavily-search.py "Hi Rasmus ABA software update 2026" --depth advanced --max-results 5 --topic news
python3 tools/tavily-search.py "PractiPal Cognitivebotics India autism therapy software update 2026" --depth advanced --max-results 6

# India market signals
python3 tools/tavily-search.py "autism therapy software India new product launch 2026" --depth advanced --max-results 8
python3 tools/tavily-search.py "DPDPA RCI autism therapy compliance update India 2026" --depth advanced --max-results 5 --include-domains "dpdpa.com,rci.gov.in,indiacode.nic.in,pib.gov.in"
```

**Step 2 — Synthesize findings** into the output format below.

**Step 3 — Save output** to:
`products/autism-therapy-platform/research/secondary/competitor-updates/YYYY-MM-DD-weekly-digest.md`

**Step 4 — Append one-line summary** to:
`products/autism-therapy-platform/research/secondary/competitor-updates/index.md`
Format: `| YYYY-MM-DD | [Key signal] | [Competitor] |`

---

## Output Format

```markdown
# Weekly Competitor Digest — [Date]

## ⚡ High-Signal Changes
> Changes that directly overlap with ATP's 3 active workstreams:
> in-session data collection · patient enrollment · treatment plans/billing

- **[Competitor]:** [What changed] — *Why it matters for ATP: [implication]*

## 📋 Routine Updates
- **[Competitor]:** [What changed]
- No significant updates: [list competitors with no changes]

## 🇮🇳 India Market Signals
- [Signal] — Source: [link]

## 💡 Strategic Implication
[1–2 sentences: what this week's changes mean for ATP's positioning or roadmap]

---
*Generated by /competitor-scan · Sources linked inline*
```

---

## Rules

- Use `python3 tools/tavily-search.py` for all searches — not WebSearch
- Tag anything with direct India relevance with 🇮🇳
- Flag any competitor feature overlapping with ATP's 3 active workstreams as ⚡ High-Signal
- If no meaningful changes found for a competitor, write "No significant updates" — do NOT fabricate content
- Cite sources inline for every claim
- Do NOT generate analysis without web search evidence

---

## Setting This as a Weekly Routine

To automate this as a weekly Claude Code Routine:
1. Open Claude Code desktop app
2. Go to Routines → New Routine
3. Set schedule: Weekly (Monday, 8:00 AM)
4. Command: `/competitor-scan`
5. Output will be saved automatically to the research folder
