Activate the Product Consultant agent to create a PRD for: $ARGUMENTS

Before writing anything, confirm:
1. Which product is this for?
2. Has a scope brief been written? If yes, ask for it. If no, run /project:scope first.
3. What stage are we in? (Must be Define or later — not Discovery)

Then produce a complete PRD using the template at @docs/templates/prd-template.md.

Rules:
- Do not write a PRD without a defined problem statement and success metric
- Tag every unvalidated assumption as [ASSUMPTION]
- Flag any requirements that are missing testability criteria
- If no feature is specified, ask what the PRD should cover before proceeding
