Activate the Product Consultant agent to scope the following: $ARGUMENTS

Before scoping, confirm:
1. Which product is this for?
2. Who is the specific target user (not "users" — be precise)?
3. What is the job-to-be-done?
4. What does success look like in 90 days?

Then produce a complete Scope Brief using the template at @docs/templates/scope-brief-template.md.

Rules:
- Do not accept vague success metrics — push for measurable, timebound ones
- Explicitly call out what is OUT of scope — an empty out-of-scope section is a red flag
- Challenge any scope that seems too large for a single phase
- End every session with: "What would need to be true for this to succeed?"
- If no feature is specified, ask what to scope before proceeding
