Convert the provided information into an SVG infographic and save it to an appropriate folder.

$ARGUMENTS should describe what to visualize. If called without arguments, use the most recently discussed data or process in the conversation.

---

## What This Skill Does

Generates a standalone `.svg` file that visually represents data, process flows, or comparisons.
The output is a clean, readable infographic suitable for embedding in reports, presentations, or documents.

---

## Step 1 — Identify the infographic type

Based on the content provided, classify it as one of:

| Type | Use when... | SVG approach |
|---|---|---|
| **Process flow** | Content describes sequential steps, stages, or a workflow | Boxes connected by arrows, left-to-right or top-to-bottom |
| **Bar chart** | Content is numeric comparisons across categories (e.g., WAU per center) | Horizontal or vertical bars with labeled axes |
| **Swimlane diagram** | Content describes steps across multiple roles or actors | Horizontal lanes, one per actor, with steps as boxes |
| **KPI card grid** | Content is a small set of named metrics (3–6 numbers) | Grid of cards, each showing a metric name and value |
| **Comparison table** | Content compares options across attributes | Visual table with colored rows or columns |

If the type is ambiguous, ask the user which type they want before proceeding.

---

## Step 2 — Determine the output path

- If the content is associated with a specific product folder, save the SVG there (e.g., `products/cognitivebotics/meetings/` or `products/autism-therapy-platform/exec-summary/`).
- If no product context is clear, save to the folder from which the source content was read.
- Use a descriptive kebab-case filename with today's date:
  `YYYY-MM-DD-[short-description].svg`

---

## Step 3 — Generate the SVG

Write the SVG directly as XML. Follow these design rules strictly:

### Design rules

**Canvas**
- Width: 900px (default). Height: auto-sized to content.
- Background: `#FFFFFF` (white)
- Font: `font-family="Inter, Helvetica Neue, Arial, sans-serif"`

**Color palette — use only these colors**
| Role | Hex |
|---|---|
| Primary fill (boxes, bars) | `#4F46E5` (indigo) |
| Secondary fill | `#7C3AED` (violet) |
| Accent / highlight | `#06B6D4` (cyan) |
| Success / positive | `#10B981` (emerald) |
| Warning / gap | `#F59E0B` (amber) |
| Neutral fill | `#F3F4F6` (light gray) |
| Border / stroke | `#E5E7EB` (gray-200) |
| Text primary | `#111827` (gray-900) |
| Text secondary | `#6B7280` (gray-500) |
| White | `#FFFFFF` |

**Typography**
- Title: `font-size="18" font-weight="700"` color `#111827`
- Section label: `font-size="13" font-weight="600"` color `#6B7280`
- Body text / labels: `font-size="13" font-weight="400"` color `#111827`
- Small / caption: `font-size="11"` color `#6B7280`

**Process flow specifics**
- Box: `rx="8"` (rounded corners), fill `#4F46E5`, text white, min-width 140px, height 48px
- Arrow: `stroke="#4F46E5"`, `stroke-width="2"`, arrowhead marker
- Decision diamond: fill `#F59E0B`, text `#111827`
- Step numbers in a circle: fill `#4F46E5`, text white, radius 14

**Bar chart specifics**
- Bars fill: use primary or cycle through palette
- Y-axis label: rotated -90deg
- X-axis labels: truncated at 16 chars with ellipsis
- Grid lines: `stroke="#E5E7EB"`, `stroke-dasharray="4,4"`
- Value labels: appear above each bar, `font-size="12" font-weight="600"`

**Swimlane specifics**
- Lane header: fill `#F3F4F6`, `font-weight="600"`, 160px wide
- Lane background alternates: `#FFFFFF` / `#FAFAFA`
- Steps: same box style as process flow

**KPI card grid specifics**
- Card: `rx="12"`, border `1px` `#E5E7EB`, fill `#FFFFFF`, shadow via `filter`
- Metric value: `font-size="32" font-weight="700"` color `#4F46E5`
- Metric label: `font-size="13"` color `#6B7280`

**Always include**
- A title at the top of the SVG
- A footer with: `Generated by Cognitivebotics PM OS · [Today's date]` in small gray text

## Rules

- **Never fabricate data.** Only visualize what is explicitly provided. Use `[DATA MISSING]` as a label if a value is absent.
- **Keep it scannable.** A management audience should extract the key message in under 10 seconds.
- **No gradients.** Flat fills only — gradients degrade when printed.
- **No clip art.** Geometric shapes and typography only.
- **Test arithmetic.** If drawing a bar chart, calculate bar heights proportionally to the actual values. Do not eyeball it.
- **Max 10 items per chart.** If content exceeds this, group or aggregate before visualizing.
