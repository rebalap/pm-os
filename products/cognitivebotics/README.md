# Cognitivebotics

This folder contains the product management operating system hierarchy for the Cognitivebotics product.

## Structure

- `CLAUDE.md` — Product context and working assumptions
- `stage-tracker.md` — Current stage and workstream tracker
- `briefs/` — Research briefs, scope briefs, and strategy documents
- `designs/` — Design artifacts, wireframes, and UI notes
- `exec-summary/` — Executive summaries, one-pagers, and key decision memos
- `meetings/` — Meeting notes and alignment summaries
- `prds-and-stories/` — Product requirements, user stories, and backlog documentation
- `research/` — Research plans, findings, and evidence
- `user-journeys/` — Journey maps and workflow definitions
